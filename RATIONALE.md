# ai-assisted-code-review: rationale

Why the skill is structured the way it is. Written by the user. Agents do not edit this file
without the user's explicit approval; propose changes in chat instead.

## 1. Orient phase with a watch-out summary

The automated PR code review usually covers this already, but we might miss it during our own
AI-assisted review, so it's best to keep everything together in one place.

## 2. Changes are made directly and their rationale recorded for the author

The skill makes the suggested changes itself and records the whole rationale for each one in a
form we can communicate to the PR author. This is mainly for cosmetic changes, where the overhead
of suggesting the change, waiting for the author to make it, and then re-reviewing is too high.
